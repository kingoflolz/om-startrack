# OM-1 with M.Zuiko Digital ED 300mm F4 IS PRO

This target uses detector geometry, not a published angle-of-view number:

- active raster: 5184 x 3888 pixels (4:3)
- nominal pixel pitch: 3.3 micrometres
- nominal focal length: 300 millimetres

OM SYSTEM specifies a [5184 x 3888 RAW
raster](https://explore.omsystem.com/hu/en/om-1). Sony Semiconductor lists a
[3.3 micrometre pitch for its 20 MP Four Thirds stacked-BI sensor
class](https://www.sony-semicon.com/en/products/is/camera/index.html). Using that
pitch for the OM-1 is an engineering inference, not a claim that OM SYSTEM has
disclosed its exact sensor model. It produces a 17.1072 x 12.8304 mm active
detector. Treat the pitch as a replaceable build input; measured metadata or a
camera calibration can supply a more precise value without changing the math.

Reproduce the calculation with the host tool:

```sh
cargo run --release -p tetra3-cli -- \
  fov \
  --active-width-px 5184 \
  --active-height-px 3888 \
  --pixel-pitch-um 3.3 \
  --focal-length-mm 300 \
  --json
```

For each detector extent `s`, the tool evaluates
`FOV = 2 * atan(s / (2 * focal_length))`. The nominal results are:

- horizontal: 3.2663496137060335 degrees
- vertical: 2.450052494119269 degrees
- diagonal: 4.082315283419089 degrees

The production index starts at 3.2 degrees horizontal FOV. This is below the
calculated 3.2663-degree full-width target and leaves a modest margin for focal
length tolerance and calibration rounding. The solver still uses calibrated
pixel-to-ray geometry at runtime; this calculation only sizes index coverage.
